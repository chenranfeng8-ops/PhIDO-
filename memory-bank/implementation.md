# PhIDO 实施文档（implementation.md）

> 本文件与 `implementation-plan.md` 对齐，当前版本仅保留**自动主线路**，移除 SAX 与分步/分布式残留线路。

## 当前实施范围

- 保留：自动引导工作流（单一路径）
- 保留：新元件生成闭环（缓存→多源→约束→生成→敏感性→仿真→反馈）
- 保留：Meep 仿真主线路
- 保留：KLayout DRC
- 移除：SAX 仿真线路
- 移除：Tidy3D 分支线路
- 移除：手动逐步/注入式线路

## 执行入口

- 详细步骤请使用：`implementation-plan.md`
- 本文仅用于对外说明“当前实施策略与边界”

## 验收标准（总览）

1. 自动主线路可从输入到 DRC 全流程执行。
2. 新元件生成流程具备缓存命中与回写能力。
3. 仿真阶段仅调用 Meep，不出现 SAX/Tidy3D 调用链。
4. 无手动分步入口可触发。
5. 日志可追溯每次生成的约束来源与反馈更新结果。
